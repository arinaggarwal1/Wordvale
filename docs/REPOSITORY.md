# Repository map

Use this page to find the source of a feature before changing it. Generated build output is not source code and should stay out of commits.

## Application code

| Path | What belongs here |
| --- | --- |
| `src/App.tsx` | App shell, navigation, and coordination between the major flows |
| `src/components/` | React screens and reusable UI, including Record, Library, Settings, and sign-in |
| `src/hooks/useWhisper.ts` | Queue state, backend process communication, and transcription lifecycle |
| `src/lib/` | Focused frontend utilities for import, export, and playback |
| `src/themes.ts`, `src/themes.css` | Theme definitions and theme styling |
| `src-tauri/src/main.rs` | Native commands, filesystem integration, and meeting-recording lifecycle |
| `src-tauri/` | Tauri configuration, app metadata, and native shell assets |
| `recorder/` | Swift audio-capture helper and its build script |
| `backend/` | Python command server, transcription support, model registry, library, and updater |
| `backend/runtime/macos-arm64/` | Versioned Apple silicon Whisper runtime libraries and executable |

## Build, docs, and checks

| Path | What belongs here |
| --- | --- |
| `scripts/` | App packaging and distribution scripts |
| `tests/` | Frontend utility tests using Node's built-in test runner |
| `backend/tests/` | Python backend tests |
| `.github/workflows/` | Release automation |
| `docs/` | Project documentation and static assets used by documentation |
| `DESIGN.md`, `PRODUCT.md` | Product and design references |

## Generated local files

These are created by installs, builds, or local tools. They are ignored by Git and can be recreated:

- `node_modules/`, `dist/`
- `backend/venv/`, `backend/__pycache__/`, `backend/build/`, `backend/dist/`, `backend/bundle_resources/`
- `src-tauri/target/`, `src-tauri/binaries/`
- `.DS_Store`, Python bytecode, and tool caches

Keep the versioned runtime under `backend/runtime/`; it is an input to packaging, not build output. `backend/bundle_resources/` and `src-tauri/binaries/` are staging destinations regenerated by `npm run build:backend`.

## Common commands

Run `npm run tauri dev` for the desktop app, `npm run dev` for the browser UI, `npm run build` for a production build, and `npm run dist:mac` to create a local macOS DMG. Backend setup and release details are in the root README.
