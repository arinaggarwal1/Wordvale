# Wordvale 0.4.0 Alpha 1

Wordvale brings local transcription to iPhone and improves Mac model downloads and recording controls.

## Downloads

- **Mac:** `Wordvale-macOS-arm64.dmg` — Apple silicon, **macOS 15+**. Drag Wordvale into Applications. Its ad-hoc signature seal is verified; it is **not Developer ID–signed or notarized**.
- **iPhone:** `Wordvale-iOS.ipa` — **iOS 17+**, version 0.4.0 build 2. **Unsigned**; re-sign and install using your own Apple account.
- **Checksums:** `Wordvale-macOS-arm64.dmg.sha256` and `Wordvale-iOS.ipa.sha256`.

With each download and its checksum file in the same folder:

```bash
shasum -a 256 -c Wordvale-macOS-arm64.dmg.sha256
shasum -a 256 -c Wordvale-iOS.ipa.sha256
```

## What’s new

- **iPhone:** Microphone recording, audio/video import, sequential transcription with Whisper/Metal, language selection, English translation, optional word timestamps, searchable library, playback, and text/subtitle/JSON exports. Models download once for offline use. No Wordvale account required.
- **Mac:** Bundled certificate roots fix model-download certificate-path failures while preserving HTTPS verification. ScreenCaptureKit permission retries and guidance improve computer-audio access. Recorder controls have balanced spacing; minimum-OS metadata now matches the bundled runtime.

## Install on iPhone

Load the IPA in [Sideloadly](https://sideloadly.io/) or [AltStore Classic](https://faq.altstore.io/altstore-classic/how-to-install-altstore-macos). Follow signing/device-trust prompts, enable Developer Mode if requested, then download Base or Tiny in Wordvale. Free-account installs normally need refreshing every seven days. Keep the bundle identifier consistent when updating. [Full guide](https://github.com/arinaggarwal1/Wordvale/blob/v0.4.0-alpha.1/ios/README.md).

## Validation and alpha limits

- Release checks passed **28 backend tests**, **6 frontend tests**, TypeScript/Swift checks, and mounted-DMG runtime/signature checks. Prior port validation passed **15 simulator tests**, including real transcription. Host inference checks covered long recordings, word timings, and cancellation. [Evidence](https://github.com/arinaggarwal1/Wordvale/blob/v0.4.0-alpha.1/ios/VALIDATION.md).
- **Physical iPhone testing remains outstanding.** Keep transcription in the foreground; leaving stops the attempt and retains audio for retry. iOS cannot capture arbitrary system audio or calls.
- Existing Mac recorder failure-handling issues remain; see the [distribution audit](https://github.com/arinaggarwal1/Wordvale/blob/v0.4.0-alpha.1/docs/DISTRIBUTION-AUDIT.md).
